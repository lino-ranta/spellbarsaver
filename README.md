# SpellbarSaver VVS Edition 

This is a conversion based on the 2.2.0.0 SpellbarSaver by Digero of Leafcull.

Some of the code was probably written by Virindi of Thistledown.

Level 8 spells have been added by me. 

Ideas or pull requests to fix tab 7 and 8 are welcome.

# KNOWN ISSUES

- plugin does not detect current spells on tab 7 and 8
- plugin will report a lot of exceptions when applying a spell list to tab 7
- plugin does not support applying a spell list to tab 8

There is some commented out code for tab 8, but both "reading" and "writing" fail with exceptions inside Decal
